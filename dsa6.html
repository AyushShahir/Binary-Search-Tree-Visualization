Insertion Algorithm 
1. if root == null → root = new Node(val)
2. else current = root
3. while true: compare val with current
4. if val < current.val → go left
5.   if current.left == null → insert left
6.   else current = current.left
7. else → go right
8.   if current.right == null → insert right
9.   else current = current.right
Deletion Algorithm 
1. Find node to delete by searching from root
2. If node has no children → remove it (leaf)
3. If node has one child → replace node with its child
4. If node has two children → find inorder successor (min in right subtree)
5. Replace node's value with successor's value
6. Delete the successor node
